单参数扫描

逐点等间距替换所选元件的参数并复用同一套求解 / 诊断；扫描在副本上进行，不会改写元件表。 电阻的起、止值都必须为正，单个采样点失败不会中断整次扫描。

两节点端口等效（戴维南）

→

对所选端口求戴维南等效：先求原网络的开路电压 V_oc（V_p − V_n）， 再将独立电压源短路、独立电流源开路，从 p 端注入 1 A 测试电流（由 n 端流出）求得等效电阻 R_eq。 端口开路本身无需改动电路；节点表变更后旧结果自动失效。

元件敏感度分析

对每个 R / I / V 元件在网络副本上分别施加 ±h 的相对参数扰动并复用 MNA 求解， 以中心差分计算目标对元件参数的归一化灵敏度（参数每相对变化 1% 时目标近似相对变化百分之几）。 结果按 |灵敏度| 排序；基准网络必须先校核求解成功，单个元件扰动失败不影响其它元件。

电阻容差包络

# 容差电阻（仅 R） 对称容差 (0.01%～50%) 操作

校核求解成功后，选择 1～8 个电阻并分别填写对称容差（0.01%～50%）， 后端枚举所选电阻下限 R(1−t) / 上限 R(1+t) 的全部 2^N 个角点组合并复用 MNA 求解， 返回目标量的最小 / 最大包络、对应极值角点、标称值与相对偏差；任一角点不可解则整体失败并标出该角点。 电路或容差配置变化时旧结果自动清空。
